# Core Trig Function
## SOH-CAH-TOA
- sinθ = Opposite/Hypotenuse
- cosθ = Adjacent/Hypotenuse
- tanθ = Opposite/Adjacent
## Inverse Trig
- θ = arcsin(O/H)
- θ = arccos(A/H)
- θ = arctan(O/A)
# Common Triangle
- 30°-60°-90°: sides in ratio 1 : sqrt(3) : 2
- 45°-45°-90°: sides in ratio 1 : 1 : sqrt(2)
# Vector Components 
## Any vector F can be broken down:
- Fx = Fcosθ
- Fy = Fsinθ
## If angle is from vertical:
- Fy = Fcosθ, Fx = Fsinθ
# Law of Sines or Cosines
## Law of Sines
- a/sinA = b/sinB = c/sinC
## Law of Cosines
- c^2 = a^2 + b^2 - 2abcosC
- Used when triangle aren't right-angled
# Dot Project 
- A * B = ABcosθ
## Application
- Work in dynamics/thermodynamics: W = Fdcosθ
- Projection of one vector onto another
# Usefel Identities
- sin^2θ + cos^2θ = 1
- tanθ = sinθ/cosθ
- sin(θ + Φ) = sinθcosΦ +- cosθsinΦ
- cos(θ + Φ) = cosθcosΦ -+ sinθsinΦ
# Polar vs Rectangular 
- Rectangular form: (x,y)
- Polar form: (r, θ), where
  - r = sqrt(x^2+y^2)
  - θ = arctan(y/x)
- Useful in thermodynamcis for cycles with pressure-volume (P-v) diagram, and in dynamics for motion problems.
